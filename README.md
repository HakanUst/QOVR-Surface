# Matrix-Driven Quartic Overhauser (QOVR) Surfaces Structural Framework: Continuity Limitations, Computer Graphics Algorithms, and Software Implementation 
### Supplementary Material: Official MATLAB Source Code and Dataset Repository

## Directory Contents
* data/QOVR_S_Ctrl_Pts_v*.xlsx: Dataset for selected internal parametric knots exported from the framework.
* src/QOVR_S_Ctrl_Pts_v*.m:  Surface visualization script.

## Execution Instructions
1. Place QOVR_S_Ctrl_Pts_v*.m and QOVR_S_Ctrl_Pts_v*.xlsx onto your Desktop directory.
2. Open QOVR_S_Ctrl_Pts_v*.m in MATLAB.
3. Click "Run" to generate the surface plot and export the graphics (SVG/PNG) automatically.

NOTE:
* When you click the "Run" button in MATLAB, a pop-up window may appear stating "File is not in the current directory". 
* You can click the "Change Folder" button.
* This ensures that MATLAB automatically syncs its working directory with the folder containing "*.xlsx", preventing any "File not found" execution errors.
